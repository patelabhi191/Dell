Setting it up. Sync is configured inside this HTML file, so your keys never sit in the browser. Open it in a text editor and search for FIREBASE SETUP, near the top of the first <script>. Set FIREBASE_ENABLED = true, paste the config from the Firebase console (Project settings → Your apps → SDK setup), and set SYNC_KEY to any private string. A databaseURL is required, so create a Realtime Database first. Save, reload, then switch sync on.

Suggested database rules:
{ "rules": { ".read": false, ".write": false, "sparta": { ".read": true, ".write": true } } }

What is stored. Under sparta/<SYNC_KEY>: core — holdings, cash, contributions, yearly finance, monthly, plan and notes; and history/<date> — one closing point per past day, intraday for today. Live prices are never synced; they are re-fetched on load.

The switch only turns syncing on or off on this device. Test connection checks the settings work, and Push / Pull move data by hand if the two copies ever disagree.

Keep data here, turned off, means this browser stores nothing of its own: the app loads from the cloud each time and forgets everything when the tab closes. Useful for trying things out without leaving rows behind that later look like real work. It needs a working cloud connection — without one a reload would start blank and the work would be gone — so it stays locked until sync is on. Your PIN is kept either way.

Live prices come from Finnhub and are separate from sync. The API key lives in this file, next to the Firebase block — search for FINNHUB_KEY. A free key from finnhub.io covers this app's request volume. With no key the app falls back to your buy price. Prices refresh every 60 seconds on their own.

In Wealthsimple (desktop browser): Profile → Documents → Generate document → Holdings report (CSV), pick your accounts, then upload the file here. Columns are detected automatically. Each deposit is filed under the year you pick, and repeat deposits in the same year add up. The log is editable — remove any entry with ✕, then re-add it with the correct amount or year. Annual limits default to the real CRA amount for whichever year you're viewing (TFSA varies by year; FHSA is C$8,000 since 2023). A new year is added automatically on Jan 1; until CRA announces that year's indexed TFSA limit, the previous year's figure is carried forward as a placeholder — update it when the official number lands — raise the limit field if you have carry-forward room (FHSA allows up to C$8,000 carried forward, so up to C$16,000 in a year; TFSA room accumulates since 2009). FHSA lifetime maximum is C$40,000. Withdrawals do not restore contribution room in the current year, so the log intentionally only tracks deposits. Check CRA My Account for your exact numbers.

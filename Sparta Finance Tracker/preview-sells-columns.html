Past sells — where the columns sit

Your marks put each column's text on an evenly spaced tick, with the buttons in a slot of their own at the end. C and D do exactly that — five equal fifths of the panel, so the text starts land on 0 / 72 / 144 / 216 / 288. A is today's build and B is the flush-ink option from the last preview, both kept for comparison.

The thing to decide is in the second band. Equal slots are a fixed grid, so a column cannot borrow room from its neighbour — and the widest real row (BRK.B · Other · 12345 · +C$116,166.00) does not fit in a fifth. It clips. A and B absorb that row because their columns size to content.

The teal rules are the fifths, drawn so you can see which option lands on them. Each frame is the real 384px right-hand Dashboard column.
